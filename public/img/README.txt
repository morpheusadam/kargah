Put the brand mark here as one of:

    kargah-logo.svg      (preferred - scales cleanly)
    kargah-logo.png      (use at least 512x512, transparent background)
    kargah-logo.webp

The first one found wins. resources/views/components/brand-mark.blade.php picks
it up automatically, so the sidebar, header, login screen and error pages all
change at once. Until a file exists, the lettermark "K" is used instead.
